# PDF Librarian workspace

The fixed 244-point sidebar centers the app icon/name, keeps four aligned workflow names, and lists selected files with resumable progress. Simplified Chinese/English flag controls sit above three theme swatches.

The middle pane holds the selected workflow’s content; the right pane holds the selected file, candidate, field, or filename detail. Their native divider is adjustable, with minimum content widths and aligned headers/footers.

Themes are blue, warm sage, and dark, using native visual-effect backgrounds with readable solid fallbacks. Five core fields share colors across metadata labels and filename previews; emoji identify field roles without entering saved metadata or filenames.

The write sheet compares actual current PDF metadata against frozen proposed values. Modified and cleared rows are explicit. No unreadable PDF is represented as an empty successful read.

Release imagery and bilingual copy live in `docs/app-store/1.5.0` and `metadata/`. Reproducible capture, workspace, and sandbox test harnesses live in `scripts/` and `tests/`.
